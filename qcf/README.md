# Madinah mushaf page fonts (QCF V2)

The 604 page fonts of the 1421H Madinah mushaf by the King Fahd Glorious Qur'an Printing Complex
(KFGQPC), converted unmodified from WOFF2 to TTF so Android and iOS can load them. Source:
https://github.com/ahmadmounir/quran-library (fonts via Tarteel's Quranic Universal Library).
All rights to the fonts belong to the King Fahd Complex. Served here for the free IFAQ app.
